# BuildMatch

## Build better. Work smarter.

BuildMatch is a simple construction platform designed to connect people who need construction work with skilled and reliable construction workers.

The idea behind BuildMatch is to make it easier for people to find the right workers for their projects and to help construction workers discover new job opportunities.

## Project Goal

Finding reliable construction workers can be difficult, while skilled workers can also struggle to find suitable jobs.

BuildMatch aims to make this connection easier through a simple and clear website.

## Features

1. Find skilled construction workers

2. Discover construction job opportunities

3. View different types of construction jobs

4. Understand how the platform works

5. Navigate easily between different sections

6. Responsive design for desktop and mobile screens

7. User login page
  
8. User sign up page

9. Navigation between the homepage, login page and sign up page

## Design

The website uses a minimal and modern visual style with a construction focused green colour palette.

The design focuses on large typography, clear sections, strong spacing and construction imagery.

## Responsive Design

BuildMatch is designed to work across different screen sizes.

CSS media queries are used to adjust the layout for smaller screens such as tablets and mobile phones.

## Image

The project includes a construction site image with descriptive alternative text to improve accessibility.

## External Resource

The website includes a link to construction safety resources from the Occupational Safety and Health Administration.
